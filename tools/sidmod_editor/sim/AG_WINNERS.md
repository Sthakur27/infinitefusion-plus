# AG WINNERS — strongest teams found in the Anything Goes search

*Generated 2026-08-01. Three independent unconstrained searches over the PC pool.*

## Method

Anything Goes = **Species Clause is the only team constraint** (plus the standard
uncompetitive-move clauses). No usage cap, no niche reservation, no archetype quotas,
legendary fusions fully legal. Run with `TIER=ubers TIER_DEF=ag PURE=1 USAGE_CAP=1.0`.

Because that search is a greedy hill-climb with no diversity pressure, a single run
converges to a **local** optimum. It was therefore run **three times with independent
seeds** (`LSEED=1/2/3`), 100 teams x 25 batches each, then the finalists were played
head-to-head across runs.

## Headline: the best MONS are settled, the best TEAM is not

Two fusions finish #1 and #2 by usage in **all three** independent runs:

| Rank | ag1 (seed 1) | ag2 (seed 2) | ag3 (seed 3) |
|---|---|---|---|
| 1 | Dragotitan 45% | Dragotitan 51% | Dragotitan 55% |
| 2 | Geyserchomp 44% | Geyserchomp 38% | Geyserchomp 47% |

**Dragonite/Regigigas** and **Azumarill/Garchomp** are the two best Pokemon in the PC,
and that result is robust to reseeding.

The best *team*, however, is not. The three runs produced three different rosters sharing
at most one member, with top Elos spread 107 points. A cross-run head-to-head gave the
winner **70.8% +/-12.9**, but the gap to #2 was only **4.2 points — NOT statistically
significant**. This looks like a real property rather than insufficient compute: the top
mons are individually so dominant that the remaining slots are close to interchangeable,
so "which six" is genuinely underdetermined in a way "which mons" is not.

## Caveats — read before trusting this

1. **The pool is stale.** All three runs used the `wsnap` snapshot, which predates ~30
   Pokemon added on 2026-08-01 and four legendary fusions (Reshiram/Mewtwo,
   Lugia/Deoxys, Rayquaza/Mewtwo, Azumarill/Lugia). Several of those are plausible
   top-slot contenders and were never eligible. Re-run on a current snapshot before
   treating this as final.
2. **The team-level margin is not significant** (4.2 points, +/-12.9 CI, 48 games per
   team). Resolving it needs roughly 10x the games.
3. **"Best" means best against this AI.** Team rankings were measured as strongly
   AI-dependent (Spearman rho ~0.14 between the native heuristic and a lookahead
   policy), so this is the answer for in-game Random Battle opponents and a softer
   claim against a human pilot.
4. Ladder Elo is **not** team strength on a converged monoculture — the head-to-head
   winner of the earlier single-run search ranked only #5 by Elo. Always settle team
   questions with a round-robin.

```bash

  ruby tools/sidmod_editor/sim/nladder.rb init <snapshot> ladder_ag1 100 12 14

  ruby tools/sidmod_editor/sim/nladder.rb run ladder_ag1 25 28 14
# ... repeat for LSEED=2,3 ... then:
ruby tools/sidmod_editor/sim/best_team_multi.rb 3 3 ladder_ag1 ladder_ag2 ladder_ag3
```
